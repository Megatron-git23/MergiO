# 📑 Merge Documents with Ease

*A lightweight Python application to merge PDF and Microsoft Word documents quickly and efficiently.*

</div>

---

## ✨ Features

- 📄 Merge multiple PDF files into one document
- 📝 Merge Microsoft Word (`.docx`) files
- ⚡ Fast and lightweight
- 🖥️ Command Line Interface (CLI)
- 🐍 Pure Python implementation
- 📂 Supports custom output filenames
- 🔰 Beginner-friendly source code
- 💻 Cross-platform support

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/MergiO.git
```

Move into the project folder

```bash
cd MergiO
```

Install dependencies

```bash
pip install PyPDF2 python-docx
```

---

## ▶️ Usage

Run the application

```bash
python main.py
```

Choose your preferred option

```
1 → Merge PDF files

2 → Merge Word (.docx) files
```
